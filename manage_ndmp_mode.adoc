= Manage NDMP mode
:imagesdir: ./media/

[.lead]
Manage NDMP mode settings to configure the scope of NDMP operations in your environment. Use these endpoints to switch between SVM-scope and node-scope modes as required for your data management tasks.

You can use this API to manage NDMP mode: SVM-scope or node-scope.

=== Examples

Updates NDMP mode to SVM:

----
 PATCH "/api/protocols/ndmp" '{"mode":"svm"}'
----

Updates NDMP mode to node:

----
 PATCH "/api/protocols/ndmp" '{"mode":"node"}'
----

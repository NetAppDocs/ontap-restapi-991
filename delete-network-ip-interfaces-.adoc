= Delete an IP interface
:imagesdir: ./media/

[.lead]
Deletes an IP interface to remove it from the network configuration, freeing up resources and ensuring the network setup reflects current needs.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/network/ip/interfaces/{uuid}`#

== Introduced in

ONTAP 9.6

== Related ONTAP commands

* `network interface delete`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|uuid
|string
|path
|True
a|IP interface UUID

|===

== Response

```
Status: 200, Ok
```

= Retrieve export policies

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/nfs/export-policies`#

*Introduced In:* 9.6

Retrieves export policies.

== Related ONTAP commands

* `vserver export-policy show`
* `vserver export-policy rule show`

== Learn more

* link:manage_nfs_export_policies.html[DOC /protocols/nfs/export-policies]

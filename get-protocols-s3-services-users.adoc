= Retrieve the SVM configuration for an S3 user

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/s3/services/{svm.uuid}/users`#

*Introduced In:* 9.7

Retrieves the S3 user's SVM configuration.

== Related ONTAP commands

* `vserver object-store-server user show`

== Learn more

* link:manage_s3_service_users.html[DOC /protocols/s3/services/{svm.uuid}/users]

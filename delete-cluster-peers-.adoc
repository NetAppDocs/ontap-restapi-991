= Delete a cluster peer
:imagesdir: ./media/

[.lead]
Removes a cluster peer to discontinue its connection with the current cluster, typically when the peer is no longer needed or is being decommissioned.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/cluster/peers/{uuid}`#

== Introduced in

ONTAP 9.6

== Usage notes

Deletes a cluster peer.


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|uuid
|string
|path
|True
a|Cluster peer relationship UUID

|===

== Response

```
Status: 200, Ok
```

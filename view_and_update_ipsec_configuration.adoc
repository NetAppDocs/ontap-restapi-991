= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Retrieve and modify IPsec configurations to manage secure communication settings within your environment. Use these endpoints to check the current IPsec status and apply updates when needed.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec

= View administrative audit logs
:imagesdir: ./media/

[.lead]
Use these APIs to retrieve administrative audit log records, which include details like timestamps, node names, and indices. You can utilize this information to monitor and review actions taken within the system.

== Overview

These APIs return audit log records. The GET requests retrieves all audit log records. An audit log record contains information such as timestamp, node name, index and so on.
 +

'''

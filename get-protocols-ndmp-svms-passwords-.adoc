= Generate and retrieve the password for an NDMP user

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/protocols/ndmp/svms/{svm.uuid}/passwords/{user}`#

*Introduced In:* 9.9

Generates and retrieves the password for the specified NDMP user.

== Related ONTAP commands

* `vserver services ndmp generate-password`

== Learn more

* link:generate_ndmp_user_password.html[DOC /protocols/ndmp/svms/{svm.uuid}/passwords/\{user}]

|Name
|Type

|Required

|path

a|SVM UUID


|user

|path

|fields
|array[string]

|===

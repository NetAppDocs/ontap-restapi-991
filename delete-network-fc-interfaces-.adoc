= Delete an FC interface

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/network/fc/interfaces/{uuid}`#

*Introduced In:* 9.6

Deletes an FC interface.

== Related ONTAP commands

* `network interface delete`

== Learn more

* link:manage_fc_network_interfaces.html[DOC /network/fc/interfaces]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|uuid
|string
|path
|True
a|The unique identifier for the FC interface.

|===

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default
```

ONTAP Error Response Codes

|===
| Error Code | Description

| 53280992
| The FC interface could not be deleted because it is enabled.
|===

= Retrieve events
:imagesdir: ./media/

[.lead]
Query observed system events to monitor and respond to changes within your environment. Use the `filter.name` parameter to refine results and focus on specific event types.

== Overview

Queries a live collection of observed events on the system.
Note: The `filter.name` parameter is used to pass a filter to be applied to the event collection returned. To retrieve the list of available filters, refer to link:get-support-ems-filters.html[/support/ems/filters]

== Example

=== Querying for the latest event received by EMS

[,json]
----

# API
GET /api/support/ems/events?fields=message.name&max_records=1

# Response
200 OK

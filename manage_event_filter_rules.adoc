= Manage event filter rules
:imagesdir: ./media/

[.lead]
Manage event filter rules to control the handling of specific instances within filters. Use these endpoints to retrieve, update, or delete individual rules as part of your event management strategy.

== Overview

Manages a specific instance of a rule within a filter.
See the documentation for link:getting_started_with_the_ontap_rest_api.html#/docs/support/support_ems_filters[/support/ems/filters] for details on the various properties in a rule.

== Examples

=== Retrieving a single instance of a rule

[,json]
----

# API
GET /api/support/ems/filters/no-info-debug-events/rules/1

# Response
200 OK

# JSON Body
{
"name": "no-info-debug-events",
"index": 1,
"type": "include",
"message_criteria": {
  "name_pattern": "*",
  "severities": "emergency,alert,error,notice",
  "snmp_trap_types": "*",
  "_links": {
    "self": {
      "href": "/api/support/ems/messages?name=*&severity=emergency,alert,error,notice&snmp_trap_type=*"
    }
  }
},
"_links": {
  "self": {
    "href": "/api/support/ems/filters/no-info-debug-events/rules/1"
  }
}
}
----

=== Updating an existing rule to use severity emergency

[,json]
----

# API
PATCH /api/support/ems/filters/test-filter/rules/1

# JSON Body
{
"message_criteria": {
  "severities": "emergency"
}
}

# Response
200 OK
----

=== Deleting a rule from an existing filter

[,json]
----

# API
DELETE /api/support/ems/filters/test-filter/rules/1

# Response
200 OK
----

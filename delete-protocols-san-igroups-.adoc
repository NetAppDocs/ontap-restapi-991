= Delete an initiator group

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/protocols/san/igroups/{uuid}`#

*Introduced In:* 9.6

Deletes an initiator group.

== Related ONTAP commands

* `lun igroup delete`

== Learn more

* link:manage_san_igroups.html[DOC /protocols/san/igroups]


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|uuid
|string
|path
|True
a|The unique identifier of the initiator group.


|allow_delete_while_mapped
|boolean
|query
|False
a|Allows the deletion of a mapped initiator group.

Deleting a mapped initiator group means that the LUNs, to which the
initiator group is mapped, are no longer available to the initiators.
This might cause a disruption in the availability of data.

*This parameter should be used with caution.*

* Default value:

|===

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default
```

ONTAP Error Response Codes

|===
| Error Code | Description

| 1254213
| The initiator group is mapped to one or more LUNs and `allow_delete_while_mapped` has not been specified.

| 5374852
| The initiator group does not exist.

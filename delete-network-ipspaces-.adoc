= Delete an IPspace object
:imagesdir: ./media/

[.lead]
Deletes an IPspace object when you need to remove network isolation settings associated with it.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/network/ipspaces/{uuid}`#

== Introduced in

ONTAP 9.6

== Related ONTAP commands

* `network ipspace delete`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|uuid
|string
|path
|True
a|IPspace UUID

|===

== Response

```
Status: 200, Ok
```

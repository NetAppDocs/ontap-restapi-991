= Retrieve Ethernet switch ports

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/network/ethernet/switch/ports`#

*Introduced In:* 9.8

Retrieves the ethernet switch ports.

== Related ONTAP commands

* `system switch ethernet interface show`

== Learn more

* link:retrieve_network_ethernet_switch_ports.html[DOC /network/ethernet/switch/ports]

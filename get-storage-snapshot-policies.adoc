= Retrieve Snapshot copy policies

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/storage/snapshot-policies`#

*Introduced In:* 9.6

Retrieves a collection of Snapshot copy policies.

== Related ONTAP commands

* `snapshot policy show`

== Learn more

* link:manage_snapshot_copy_policies.html[DOC /storage/snapshot-policies]

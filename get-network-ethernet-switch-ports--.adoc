= Retrieve an Ethernet switch port

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/network/ethernet/switch/ports/{switch}/{identity.name}/{identity.index}`#

*Introduced In:* 9.8

Retrieves an ethernet switch port.

== Related ONTAP commands

* `system switch ethernet interface show`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|switch
|string
|path
|True
a|Switch Name


|identity.name
|string
|path
|True
a|Interface Name


|identity.index
|integer
|path
|True
a|Interface Index


|fields
|array[string]
|query
|False
a|Specify the fields to return.

|===

= Delete an event destination

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/support/ems/destinations/{name}`#

*Introduced In:* 9.6

Deletes an event destination.

== Related ONTAP commands

* `event notification destination delete`
* `event notification delete`


== Parameters

[cols=5*,options=header]
|===

|Name
|Type
|In
|Required
|Description

|name
|string
|path
|True
a|Destination name

|===

== Response

```
Status: 200, Ok
```

== Error

```
Status: Default
```

ONTAP Error Response Codes

|===
| Error Code | Description

| 983152
| Default destinations cannot be modified or removed
